# AI Math AZ — прототип «к концу года»

Интерактивный прототип платформы AI Math AZ (математика, 4 класс) в том виде, какой она станет к концу 2026 года: экран учителя и планшет ученика рядом, на одном уроке. Всё новое помечено значком **✦ новое**.

Прототип статический — без сервера и сборки. Данные вымышленные, реальных учеников нет.

## Как открыть

- Локально: открыть `index.html` в браузере.
- Онлайн: GitHub Pages → Settings → Pages → Deploy from a branch → `main` / root. Прототип откроется по адресу `https://<аккаунт>.github.io/<репозиторий>/`.

## Как пользоваться

- Сверху переключатель вида: **Учитель + ученик**, **Только учитель**, **Только ученик**. Кнопка **Сбросить** возвращает урок в начало.
- Справа — планшет ученика. Над ним выбирается, чей планшет показать.
- Ввод ученика заменён кнопками (**Ответить верно / с ошибкой**, **Решить с помощником** и т. д.). Кнопки **👥** симулируют остальной класс.

## Сценарий демонстрации

1. **Урок → Начать урок → Разминка → Старт.** Ученик отвечает, «👥 Ответы класса», учитель — «Показать решение ученикам».
2. **Решаем вместе.** Если ошиблись трое и больше, учитель получает **ИИ-подсказку**, как разобрать ошибку (оценивается 👍/👎).
3. **Практика.** Live-карта класса, очередь поднятых рук. Ученик ошибся → **✦ Решить с помощником**: ИИ ведёт по шагам, не давая готовый ответ; учитель видит ✦ в ячейке.
4. **✦ Бонус.** Кто прошёл практику и решил 70%+, получает бонусные задания от ИИ; учитель видит, сколько учеников дошли.
5. **Завершить урок → ✦ персональная домашка.** ИИ распределяет класс по наборам (работа над ошибками / закрепление / бонус), учитель может изменить и подтверждает. У ученика на главной — своя домашка.
6. **Мой класс → ✦ Навыки.** Освоение навыков класса пересчитывается по ответам, рекомендация ИИ.
7. **На проверку → ✦ ИИ-предпроверка фото.** ИИ заранее отмечает пункты чеклиста, учитель сверяет и подтверждает; ученик видит результат по критериям.
8. **✦ Разбор урока.** ИИ-аудиокоуч по записи урока, загруженной учителем: баланс речи и рекомендации.
9. **Ученик → Карта знаний ✦ по навыкам:** освоено / в процессе / пробел.

## Допущения

- ИИ-помощник встроен в экран задания; учитель видит, кто решает с помощником.
- Бонус открывается после всей практики при 70%+ решённых заданий.
- ИИ только предлагает: оценку фото и персональную домашку подтверждает учитель.
- Аудиоанализ — по записи, которую загружает учитель; непрерывной записи платформа не ведёт.
- Цифры навыков, тексты помощника и рекомендаций — иллюстрация.
