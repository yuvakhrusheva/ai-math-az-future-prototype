# AI Math AZ — прототип «к концу года»

Интерактивный прототип платформы AI Math AZ (математика, 4 класс) в том виде, какой она станет к концу 2026 года: экран учителя и планшет ученика рядом, на одном уроке. Всё новое помечено значком **✦ новое**.

Прототип статический — без сервера и сборки. Данные вымышленные, реальных учеников нет.

**Открыть:** https://yuvakhrusheva.github.io/ai-math-az-future-prototype/

## Как пользоваться

- **▶ Показать функцию…** (меню сверху) — сразу открывает нужную функцию в готовом состоянии урока.
- Переключатель вида: **Учитель + ученик**, **Только учитель**, **Только ученик**. **Сбросить** — урок с начала.
- Справа — планшет ученика; над ним выбирается, чей планшет показать.
- Кнопки ученика — прямо на экране планшета, как на платформе. Ввод ответа заменён кнопками под планшетом; кнопки **👥** симулируют остальной класс.

## Функции

1. **ИИ-подсказка учителю по фронтальной работе.** В разминке и «Решаем вместе»: если ошиблись трое и больше, учитель получает совет, как разобрать ошибку, и оценивает его 👍/👎. На главной учителя — какие подсказки сработали.
2. **✦ ИИ-помощник ученику.** Ученик ошибся в практике → «✦ С помощником» на планшете. Без отдельного чата и без скролла: ИИ подсвечивает нужные окошки прямо в задании и даёт одну короткую подсказку на шаг. Учитель видит ✦ в ячейке live-карты.
3. **✦ Бонус.** Открывается каждому, кто закончил практику: кто решил 70%+ с первой попытки — задания посложнее, остальные — похожие на те, где ошибся.
4. **✦ Персональная домашка.** У каждого ученика свой набор с подписью, почему задание попало: ошибки этого урока → слабые навыки → закрепление → задачи посложнее. Учитель видит состав по каждому ученику, может убрать лишнее и подтверждает.
5. **Карта знаний ученика** — по урокам, как на платформе: прогресс по каждому уроку и **дорешивание** нерешённых заданий.
6. **✦ Навыки каждого ученика** (Мой класс): таблица «ученик × навык», по клику — детали ученика и что попало в его домашку.
7. **✦ ИИ-предпроверка фото.** ИИ заранее отмечает пункты чеклиста, учитель сверяет и подтверждает; ученик видит результат по критериям.
8. **✦ ИИ-аудиокоуч.** По записи урока, загруженной учителем: баланс речи и рекомендации.

## Персонализация по шагам

| Шаг | Где в прототипе |
|---|---|
| Одна программа для класса | Урок: все решают одни задания, учитель видит ошибки каждого |
| Похожие задания | Бонус: похожие задания на тот же навык — посложнее или по своим ошибкам |
| Работа над ошибками | Домашка: задания, похожие на те, где ученик ошибся на уроке |
| Задания по навыкам | Домашка: задания на навыки, которые у ученика в пробеле или в процессе |

## Допущения

- ИИ только предлагает: оценку фото и персональную домашку подтверждает учитель.
- Аудиоанализ — по записи, которую загружает учитель; непрерывной записи платформа не ведёт.
- Статус навыков ученика считается по его ответам на уроке и в практике (первая попытка — «освоено», с помощником или со второй — «в процессе»).
- Цифры, тексты подсказок и рекомендаций — иллюстрация.
